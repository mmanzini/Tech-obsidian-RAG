# Model-Driven Development

A software engineering methodology where formal **models** — not source code — are the primary artefact guiding development. Engineers describe a system at a high level of abstraction; automated **transformations** carry those models down to lower-level models and, eventually, running code. The model is the source of truth; code is a generated by-product. Companion methodology to [[../spec-driven-development/_index|Spec-Driven Development]], which treats the specification as the durable artefact and lets humans or agents write the code.
